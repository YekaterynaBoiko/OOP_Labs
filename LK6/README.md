# OopDefense_Part2 — код для захисту з ООП (C#), частина 2

Рішення містить три проєкти (модуль M3 складається з двох):

| Проєкт | Тип |
| --- | --- |
| `M3.Payments.Contracts` | бібліотека класів — інтерфейси оплати |
| `M3.Payments.App` | консольний застосунок — каса (посилається на `M3.Payments.Contracts`) |
| `M4.Shop` | консольний застосунок — магазин |

## Як запустити

**Visual Studio / Rider:** відкрийте `OopDefense_Part2.sln`, клацніть правою кнопкою на потрібному проєкті → *Set as Startup Project*, натисніть F5 (або Ctrl+F5). `M3.Payments.Contracts` — бібліотека, її не запускають.

**Термінал:**

```
dotnet run --project M3.Payments.App
dotnet run --project M4.Shop
```

Потрібен .NET SDK 8 або новіший. Кожен застосунок друкує кілька сценаріїв `S1`, `S2`, … — це методи в його `Program.cs`.

## Підказки українською

Наведіть курсор миші на назву класу, інтерфейсу, методу, властивості чи поля — з'явиться підказка українською: що це, що робить і від чого наслідується. Підказки працюють у Visual Studio, Rider і VS Code (з розширенням C# Dev Kit); вони написані в коді як коментарі `/// <summary>`.
